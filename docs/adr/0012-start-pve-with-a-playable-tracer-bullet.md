# Start PvE with a playable tracer bullet

The first implementation slice for the PvE spin-off will be a minimal playable tracer bullet: launch the separate app, remove multiplayer/auth/lobby/shrinking-zone surfaces from the play flow, enter airborne play quickly, show a minimal HUD, and support an end-of-run path. Enemy waves, pickups, scoring, and PostgreSQL ranking can then be layered onto a verified standalone loop.
